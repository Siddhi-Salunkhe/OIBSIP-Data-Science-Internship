# Task 1 - Iris Flower Classification

## Objective

The objective of this project is to build a machine learning model that classifies Iris flowers into different species based on their measurements.

## Dataset

The Iris dataset contains measurements of:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files

- `Siddhi_Task1_Iris_Flower_Classification.ipynb` - Complete machine learning notebook.
- `requirements.txt` - Required Python libraries.

## Conclusion

This project demonstrates the use of machine learning to classify Iris flower species based on their measurements.
