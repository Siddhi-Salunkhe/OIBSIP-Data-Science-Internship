# 📊 OIBSIP Data Science Internship

## 📌 Internship Overview

This repository contains the projects completed as part of my **Data Science Internship** at **Oasis Infobyte (OIBSIP)**.

The internship provided hands-on experience in Data Science, Machine Learning, Data Analysis, Data Visualization, and model development using Python.


## 🎯 Objective

The main objective of this internship is to gain practical experience in solving real-world problems using:

- Python
- Data Analysis
- Data Visualization
- Machine Learning
- Classification
- Regression
- Model Evaluation

## 📂 Projects

### 🌸 Task 1 — Iris Flower Classification

A machine learning classification project that predicts the species of an Iris flower based on its sepal and petal measurements.

**Algorithms Used:**

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

**Techniques Used:**

- Exploratory Data Analysis
- Data Visualization
- Feature Selection
- Train-Test Split
- Model Training
- Model Evaluation
- Cross-Validation
- Model Comparison

📁 Folder:

`Task-1-Iris-Flower-Classification`



### 🚗 Task 3 — Car Price Prediction

**Techniques Used:**

- Data Cleaning

- Data Preprocessing

- Regression
- Model Training
